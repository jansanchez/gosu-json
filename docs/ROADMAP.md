# Roadmap

Implemented: lossless virtualized tree/syntax-colored CodeMirror editor, paginated tables, copy actions, search, structural diff, file workflow, local themes and optional domain capture.

Next, after browser validation and user feedback:

1. DevTools response import and robust native JSON-viewer adapters.
2. Full JSONPath queries (paths are currently copied only), selectable table columns and export selections.
3. Array diff alignment by a chosen key, such as `id`.
4. JSON Schema validation and NDJSON support, loaded on demand.
5. localization and deeper accessibility review.
6. Execute the included Safari packaging workflow and validate the native app and extension.

No AI, remote sync, endpoint write client or broad background monitoring is planned for the initial release.
